# Linux Commands for Ethical Hacking

My daily Linux commands as I learn Ethical Hacking.

## 1. Navigation
- pwd - show where I am
- ls -la - list all files
- cd .. - go back one folder
- cd /home - go to home

## 2. Files
- cat file.txt - read a file
- touch notes.txt - create empty file
- mkdir hacking - create folder
- rm file.txt - delete file

## 3. Network - Most Important for Hackers
- ifconfig - check my IP
- ping google.com - check connection
- netstat -tulpn - see open ports
- ip a - show network info

## 4. Users & Permissions
- whoami - who am I logged in as
- sudo su - become root/admin
- chmod +x script.sh - make file executable
